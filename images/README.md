# images 文件夹说明

此文件夹用于存放风水器物产品图片和收款二维码。

## 产品图片（6张）

请将图片命名为以下文件名，放入本文件夹：

| 文件名 | 对应产品 | 建议尺寸 |
|--------|---------|---------|
| `产品-大象.jpg` | 招财大象 | 宽600px+，比例4:3 |
| `产品-孔雀.jpg` | 开运孔雀 | 宽600px+，比例4:3 |
| `产品-葫芦.jpg` | 福禄葫芦 | 宽600px+，比例4:3 |
| `产品-聚宝盆.jpg` | 聚宝盆 | 宽600px+，比例4:3 |
| `产品-铜钱葫芦.jpg` | 铜钱葫芦 | 宽600px+，比例4:3 |
| `产品-罗盘.jpg` | 风水罗盘 | 宽600px+，比例4:3 |

## 收款二维码（2张）

| 文件名 | 对应方式 |
|--------|---------|
| `微信收款码.jpg` | 微信支付 |
| `支付宝收款码.png` | 支付宝 |

> 建议二维码图片尺寸：300×300px 以上，PNG 或 JPG 格式均可。
